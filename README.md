# PeopleNoStudy v0.1.0

作者：Kesselring

带中文右上角悬浮窗的 Chrome 自动答题扩展。接入 OpenAI 兼容模型，通过两轮 AI 交互识别题目、生成答案，再通过浏览器原生输入填写当前页。支持已授权的 iframe、普通文本框及部分代码编辑器。

## 安装

需要 Chrome 120 或更高版本。本目录为已构建的扩展，无需安装 Node.js 或执行构建命令。

1. 如果下载的是 ZIP 安装包，先解压到固定目录。
2. 打开 `chrome://extensions/`，启用右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的本目录。
4. 在 Chrome 工具栏固定 PeopleNoStudy，打开答题网页，点击扩展图标即可显示右上角悬浮窗。

不要直接选择 ZIP 文件，也不要选择不含 `manifest.json` 的源码项目根目录。更新文件后，在扩展管理页点击「重新加载」，刷新答题网页并重新打开悬浮窗。

## 配置与使用

1. 打开悬浮窗中的「模型设置」，填写 API Base URL，例如 `https://api.openai.com/v1`，不要加 `/chat/completions`。
2. 填写 API Key。本地免鉴权服务可以留空。
3. 点击「拉取模型」后选择模型；服务不提供模型列表时，可以手动填写模型 ID。
4. 按需设置超时和额外答题要求，测试连接并保存。首次访问模型服务时，需要授权对应域名。
5. 返回答题页，点击「开始填写」。跨域 iframe 需要额外授权，未授权区域会跳过。
6. 查看每题的答案、理由和执行结果，自行核对后手动提交。运行中可点击「立即停止」。

悬浮窗可以拖动、折叠和关闭。关闭窗口只隐藏界面，不会停止任务；停止请使用「立即停止」。输入期间窗口会暂时隐藏，以便点击其下方的答题控件，随后恢复。

## 行为与数据说明

- 仅填写当前页，默认保留 AI 判断为已作答的题目，不自动翻页，也不主动点击提交。切换标签页、页面跳转或调试连接断开会停止任务。
- 使用时会向所配置的模型服务发送当前页及已授权 iframe 的完整 HTML、开放 Shadow DOM 和实时控件信息，不进行 HTML 隐私过滤；不额外读取 Cookie、浏览器存储或网络凭据。
- API Key 保存在扩展本地存储，仅供扩展可信上下文访问。模型请求可能产生所选服务的费用。
- 原生输入使用 Chrome 调试接口，Chrome 会显示调试提示；系统鼠标指针不会移动，也不会占用剪贴板。
- 模型识别、答案和代码排版需要自行核对。图片、Canvas、封闭 Shadow DOM 及部分复杂编辑器等场景仍有限制。
- 网站自身的自动保存、自动切题或自动交卷行为无法由通用扩展可靠阻止。
